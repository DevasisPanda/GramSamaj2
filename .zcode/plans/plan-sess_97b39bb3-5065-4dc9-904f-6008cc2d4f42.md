## AIRD Website — Frontend-Only Build Plan (revised)

### Key clarifications locked in
- **Frontend only.** No backend, member system, or admin-auth is wired now — `ngo-management-system` will connect later. The site runs fully on typed **mock data** shaped exactly like the prompt's tRPC interfaces (`Villager`, `Donor`, `ActivityEvent`, `MembershipRecord`), so the later swap is a one-file change.
- **Skeleton informed by the "Important websites" doc.** Those 7 links are the governance framework AIRD operates inside, so they become a curated **"Important Websites / Resources"** section (footer-linkable + a dedicated block), each opening in a new tab with a short descriptor:
  - SDGs — un.org/Wikipedia Sustainable Development Goals
  - Gram Swaraj Abhiyan (RGSAPortal) — rgsa.gov.in
  - GPDP — Gram Panchayat Development Plan portal, gpdp.nic.in
  - DAY-NRLM — Deendayal Antyodaya Yojana–NRLM, myscheme.gov.in
  - MGNREGA / Viksit Bharat — facebook.com/IndiaRuralDev
  - Social Audit UP — socialauditup.in
  - **DDU-SIRD UP — sird.up.gov.in** (apex rural-dev training institute; its 17 RIRDs are KRANTI's Phase II expansion target — explicitly called out on the KRANTI page)

### Target
New React 19 + Vite + TypeScript project at **`F:\VS Code\NGOWork2\Frontend`** (sibling of `Work/`). Reuses the proven `NGO_Work/Frontend` conventions (`@/*` alias, `createTRPCReact<any>()` scaffold dormant behind mock data, Tailwind, Radix, Sonner, jsPDF/html2canvas/zod).

### Admin (`wouter` under `/admin/*`) — UI scaffolding now, logic later
Dashboard (Recharts: BarChart donations vs fees, LineChart member growth, PieChart village demographics) · Villagers manager (search/paginate/CSV export/inline edit — reads mock data) · Event scheduler (form → mock mutation clears query cache) · Media center (drag-drop gallery + video manager UI). Auth = simple AdminGate stub (placeholder login) so routes are reachable; real auth comes with the member-system backend.

### Data Layer
- `lib/mockApi.ts` exposes typed query/mutation functions matching the prompt's interfaces, consumed via @tanstack/react-query hooks.
- `lib/trpc.ts` scaffolded (`createTRPCReact<any>()` + `VITE_TRPC_URL` knob), dormant until `ngo-management-system` connects.

### Build verification
`npm install` → `npm run build` (tsc strict + vite) passes; `npm run dev` serves a fully clickable site on mock data.

### Build order
1. Scaffold (package.json, vite, tailwind w/ AIRD palette, tsconfig `@/*`, index.css, fonts).
2. `components/ui/*` + `components/shared/*` (Header/Footer/SloganTicker/TranslateWidget/Layout/ImportantLinks).
3. `lib/` + `data/` (constants, mockApi, queryClient, importantLinks) + `utils/documentEngine.ts`.
4. Public pages: Home → About → Philosophy → KRANTI → Join → Donate.
5. Admin (Layout + 4 panels) + Recharts + AdminGate stub.
6. `App.tsx` routing + `main.tsx`; build & fix until green.
