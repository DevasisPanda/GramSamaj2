# Appropriate Institute of Rural Development (AIRD Trust)

> **Gram Swaraj &bull; People's Governance &bull; Participatory Rural Development**  
> Registered Public Charitable Trust | Reg. No: 9002139 IV-66/2020 | NGO Darpan: UP/2022/0303967

Official web portal and digital administration system for Appropriate Institute of Rural Development (AIRD Trust), Lucknow, Uttar Pradesh.

---

## 🌟 Features

- **Gram Swaraj Portal**: Comprehensive documentation of AIRD's participatory governance philosophy, historical background, and live model village initiatives.
- **Village Garhi Model**: Participatory GIS village directory and demographic breakdown.
- **Spiritual & Development Philosophy**: Development Car, Teachings, and Annual Reports.
- **Dual Language Support**: Seamless English and Hindi (`EN` / `हिन्दी`) language toggle.
- **Membership & Donations**: Online public enrollment and donation processing.
- **Administrative Portal**: Secure admin portal for village records, media management, and event calendar.

---

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS + Custom Saffron & Forest Green Design System
- **State & Data**: TanStack Query (React Query)
- **API Integration**: tRPC client with resilient offline fallbacks
- **Icons & UI**: Lucide React + Radix UI Primitives + Sonner Toasts

---

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+ (or 20+)
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install

# Start local development server (runs on http://localhost:5173)
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
